# Até a Tampa 🍰

Uma confeitaria artesanal especializada em bolos de pote e bolos festivos sob encomenda, dedicada a transformar receitas tradicionais em experiências memoráveis, seja na praticidade do dia a dia ou em grandes festividades.

## Instalando

1. Clone o repositório:

```bash
git clone https://github.com/isahxs/ateatampa.git

cd ateatampa
```

2. Instale as dependências:

```bash
npm install
```

3. Crie o arquivo de ambiente:

```bash
cp .env.example .env
```

4. Configure o arquivo `.env` com as credenciais necessárias para execução do projeto.

5. Inicie o servidor de desenvolvimento local:

```bash
npx expo start
```
